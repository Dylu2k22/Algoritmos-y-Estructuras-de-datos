## Descripción General

Este repositorio contiene las resoluciones de los trabajos prácticos de la materia **Estructuras de Datos y Algoritmos**. Todas las soluciones fueron desarrolladas en Java utilizando Visual Studio Code y desarrollo asistido por IA (OpenCode / VS Code Agents).
